## Pipeline

```
source/raw/      blog text as published (ESV). Generated by tools/extract.mjs. Never edit.
source/auto/     snapshot of chapters/ straight out of tools/convert.mjs, before hand edits.
                 diff chapters/ against this to see every hand change.
chapters/        THE MASTER TEXT. Hand-edited. Do not re-run convert.mjs --force over it.
front/, back/    copyright, introduction, about the author.
book.config.json title, author, trim, divine name, BSB paths, Chrome path.
tools/build.mjs  -> dist/book.html (web), dist/print.html + dist/Meditations-on-Psalm-119.pdf
```

Commands (run in this folder):

- `node tools/build.mjs` — web HTML only
- `node tools/build.mjs --pdf` — HTML + PDF (~30 s; two layout passes so the index gets page numbers)
- `node tools/build.mjs --pdf --trim 6x9` — same, at 6 × 9 in (dist/Meditations-on-Psalm-119-6x9.pdf)
- `python tools/preview.py 1,2,3 out.png [dpi]` — render PDF pages to an image
- `node tools/verify.mjs` — check every Scripture quotation against the BSB (run after any edit)
- `node tools/apply.mjs chapters/NN < edits` — exact find/replace edits; `{{BSB:ref}}`, `{{BSBN:ref}}`, `{{FN:ref}}`
  expand to BSB text. `python tools/apply.py chapters/NN-*.md < edits` is the same edit format without the `{{...}}` expansion. `node tools/vv.mjs "Romans 8:28"` prints BSB text.

## Markdown conventions in chapters/

- `## Heading` = section heading inside a chapter (chapter title comes from front matter).
- Scripture quotation block:
  ```
  > <sup>3</sup>verse text <sup>4</sup>verse text
  > <cite>Psalm 18:3–4</cite>
  ```
  A blockquote with `<cite>` is styled as Scripture. Verse numbers only when more than one verse.
- Footnotes: `[^n]` in the text, `[^n]: ...` at the bottom of the file. Numbering restarts each chapter.
- A footnote may add an author's note after the verse text in parentheses: `[^3]: Romans 13:9 — text (note.)`. verify.mjs accepts it.
- Scripture references in plain text (e.g. “Romans 8:28”) are found automatically for the index.

## Technical notes

- Psalm superscriptions (“For the choirmaster…”) are merged into verse 1 in the BSB data; they were stripped
  by hand from footnotes. New footnotes for a psalm’s verse 1 need the same treatment.
- convert.mjs had a bug that kept only the first passage of a blockquote quoting several references; the five
  affected places (chs 30, 31, 37, 39, 43) were fixed by hand. Don’t re-run it.

- The confession project's `bsb.json` already has LORD → Yahweh applied; `bsb.txt` is the untouched BSB (LORD).
  `book.config.json` `divineName` picks which one is used.
- `bsb.json` carries KJV text for verses the BSB omits (e.g. Matt 17:21); none of those are quoted in the book so far.
- Paged.js quirks: CSS `target-counter()` and `counter-reset: page` are unreliable, so page numbers for the
  contents and index are measured in pass 1 and written in pass 2. Pages are numbered straight through from
  the half-title (no roman front matter). Footnote numbers are written explicitly, not CSS counters.
- Scripture index: run-in, one line per chapter. A chapter's references to its own four verses are left out.
  After pass 2, build.mjs adds "Book (cont.)" labels at continued column tops and sets the running head to the
  page's book range ("Psalms – Malachi"); each continued index page reserves one empty line for the labels.
